🎓 Faculdade

Repositório com as atividades, exercícios e trabalhos desenvolvidos durante o curso de Tecnólogo em Análise e Desenvolvimento de Sistemas (ADS) na UNICID, com foco nas disciplinas de desenvolvimento web (HTML5, CSS3 e JavaScript).

📁 Estrutura do repositório

O repositório está organizado por data das atividades e por tipo de entrega:


Faculdade/
├── 19-08-2026/       # Atividades da aula/entrega do dia 19/08
├── 26-08-2026/       # Atividades da aula/entrega do dia 26/08
├── 02-09-2026/       # Atividades da aula/entrega do dia 02/09
├── Praticando/        # Exercícios de prática e estudos livres
├── Trabalho 01/       # Trabalho 01 (arquivos-fonte)
└── Trabalho 01.7z     # Trabalho 01 compactado (versão para entrega)

💡 As pastas com datas seguem o padrão DD-MM-AAAA e reúnem o material referente àquela aula ou prazo de entrega.

🛠️ Tecnologias utilizadas
HTML5 — estruturação semântica das páginas (header, nav, main, section, article, aside, footer)
CSS3 — estilização e layout, com uso de CSS Grid para posicionamentos mais complexos
JavaScript — interatividade (conforme o curso avança para essa etapa)
🚀 Como visualizar os projetos
Clone o repositório:
bash
   git clone https://github.com/rrenatodevs/Faculdade.git
Entre na pasta da atividade desejada.
Abra o arquivo .html correspondente diretamente no navegador, ou utilize uma extensão como o Live Server (VS Code) para uma visualização com recarregamento automático.
